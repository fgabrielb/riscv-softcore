# RV-32I CPU made with Verilog (work in progress)

## Design Choices:
### 32 bits
Since it's just an educational project, I decided to keep it in 32 bits for simplicity.

### Single-Cycle
By now, it's a single cycle cpu, i.e. executes only one instruction per clock cycle, because it's easier to check the correctness that way. Pipelinig will be added in the future.
